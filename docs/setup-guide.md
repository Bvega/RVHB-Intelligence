# Setup Guide

Complete instructions for developers building or modifying the toolkit.

---

## Prerequisites

- Python 3.9 or higher
- Microsoft Excel 2016 or higher (Windows or Mac)
- Git

### Python dependencies

```bash
pip install openpyxl xlrd
```

---

## Building the workbook from source

The workbook is generated by a Python script — you never manually edit the `.xlsm` file directly.

```bash
# From the project root
python3 src/python/build_toolkit.py
```

Output lands in `dist/HB_Intelligence_Toolkit.xlsm`.

---

## Populating VBA source files

If the `src/vba/` files are empty (fresh clone), run:

```bash
python3 src/python/write_vba_sources.py
```

This writes all four `.bas` files with their correct content.

---

## Importing VBA into Excel

Always import in this order:

1. `HB_Core.bas` — must be first (other modules depend on its constants)
2. `HB_Module1_Ingest.bas`
3. `HB_Module2_RFP.bas`
4. `HB_Module3_Benchmark.bas`

Steps:
1. Open the `.xlsm` file in Excel
2. Press `Alt + F11`
3. `File` → `Import File` → select each `.bas` file in order
4. Close the VBA editor
5. Save the workbook

---

## Assigning macros to buttons

On the Home sheet, right-click each button and select **Assign Macro**:

| Button | Macro name |
|--------|-----------|
| Update with New Year's Report | `IngestNewReport` |
| Format RFP | `FormatRFP` |
| Benchmark | `RunBenchmark` |
| Refresh Dashboards | `RefreshDashboard` |

```bash
# Verify the sample file is present
ls data/samples/
```

## Creating a new release

1. Build the workbook: `python3 src/python/build_toolkit.py`
2. Test ingestion with the sample report
3. Copy outputs to the release folder:

```bash
cp dist/HB_Intelligence_Toolkit.xlsm releases/vX.X/
cp dist/HB_Macros.bas releases/vX.X/
```

4. Update `docs/changelog.md`
5. Commit and tag:

```bash
git add .
git commit -m "release: vX.X — description"
git tag vX.X
```

---

## Adding a new module

1. Create `src/vba/HB_ModuleN_Name.bas`
2. Add the public entry `Sub` (e.g. `RunModuleN()`)
3. Add a button placeholder on the Home sheet in `src/python/build_toolkit.py`
4. Import the new `.bas` into Excel
5. Assign the macro to the new button
6. Update `docs/module-roadmap.md` and `docs/changelog.md`
